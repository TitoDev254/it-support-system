# IT Support & Asset Management System

A PHP and MySQL-based system designed to help organizations manage IT assets and support requests efficiently.

## 🎯 Aim

The aim of this system is to simplify IT asset management and support ticket handling by providing a centralized platform for administrators and staff.

## 🚀 Features

### Admin
- Admin login
- Dashboard with system statistics
- Add IT assets
- Edit and delete assets
- Manage users
- Assign assets to staff
- Manage support tickets
- Update ticket status
- View ticket details

### Staff
- Staff login
- Staff dashboard
- View assigned assets
- Create support tickets
- View submitted tickets
- Track ticket status
- View ticket details

## 🛠️ Technologies Used

- PHP
- MySQL
- HTML5
- CSS3
- XAMPP
- Git & GitHub

## 💻 Local Installation

1. Install XAMPP.
2. Copy the project into:

   `C:\xampp\htdocs\`

3. Start Apache and MySQL from XAMPP.
4. Create the required MySQL database.
5. Configure the database connection in:

   `config/database.php`

6. Open the project in your browser:

   `http://localhost/it-support-system/`
